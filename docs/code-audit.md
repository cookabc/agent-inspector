# 代码审查与验证记录

日期：2026-10-22。范围：当前源码、五个工具适配器、HTTP 边界、文件与数据库写入、扫描与缓存、前端交互、测试入口和文档。

本轮保留零运行依赖和现有界面结构，把主要改动集中在数据安全、行为正确性和持续验证。没有对真实会话执行删除或回灌。以下记录推送前的本地验证；远程检查结果见对应提交的 [GitHub Actions](https://github.com/cookabc/zcode-inspector/actions/workflows/ci.yml)。

## 已落实的改动

| 领域 | 修正后的行为 | 主要验证 |
|---|---|---|
| 备份 | 每次独立目录，主库复制错误不能被吞掉，存在的异常侧文件不能跳过；校验内容并同步普通文件 | 空文件、连续备份、主库缺失、异常侧文件 |
| 数据库事务 | 所有库先取得写锁；SQL 和检查全部通过后才提交；提交前失败回滚全部未提交更改 | 第二个库执行失败、第二个库被占用、外键与恢复副本 |
| 写入边界 | 数据库写路径检查祖先符号链接；HTTP 写操作互斥；退出时等待已开始的写操作 | 越界链接、重叠写调用 |
| 进程状态 | `pgrep` 只有退出码 1 表示无匹配，其他失败返回未知状态并阻止数据库写入 | 命令缺失、权限错误、非正常退出 |
| ZCode | 清理父任务前检查全部后代；正文库与任务索引同步清后代；可选表缺失可预览，现存表写失败必须回滚 | 活跃子任务、后代预览、索引触发器故障 |
| Codex | 当前运行时不再仅凭路径归为旧版本；current 必须解析到有效 release；正文在根目录外不等于正文缺失 | 当前与旧版本分类、既有会话清理测试 |
| Cursor 清理 | 未知键族引用、保留 blob 的后代引用都阻止连带删除；写锁内重算计划；自检失败不报成功 | 共享引用、未知键族、无主 blob 的后代、既有位集边界 |
| Cursor 回灌 | 缺会话头时仍检查已有正文；插入失败回滚；空选择不能解释为全部回灌；头索引不可读时不判孤儿 | 已有 KV 保留、空选择、索引不可读、幂等 |
| Claude | 正文路径从工具根开始，能与文件清单匹配；不把文件符号链接当会话读取 | `projects/` 路径匹配及浏览器完整清理流程 |
| 扫描与缓存 | 更新目录存在性；读取问题显式上报；写操作前后失效关联缓存；旧扫描不能重新写入新缓存 | 启动后创建目录、文件删除后立即读取会话列表 |
| HTTP 与 CLI | 严格校验 ID、布尔值和参数；拒绝重叠路径；过大请求返回 JSON 413；gzip 尊重 q=0；随机端口显示实际地址 | 参数、重叠路径、过大请求和既有跨站保护测试 |
| 前端 | 请求代次隔离旧结果；处理中确认词输入不能重新启用按钮；部分成功保留失败原因；删除后刷新会话；记住「全部」 | 浏览器延迟响应、处理中输入、删除后空态、刷新保留视图 |
| 工程与文档 | 可移植检查脚本只遍历源码；测试备份隔离；README 说明当前契约、恢复步骤和限制；维护规则进入 CONTRIBUTING | 语法检查、测试、差异检查 |
| Node 兼容性 | 不把 Node 22.5 的 SQLite 空结果对象当成命中行；扫描连接强制 `query_only`，补足早期 Node 忽略 `readOnly` 的问题 | 空结果、只读连接拒绝 DELETE，及真实 Node 22.5、24、26 完整检查 |

## 回归证据

在独立临时目录导出修复前的 `HEAD`，只移植以下 9 条新增测试并执行。结果为 **0 通过、9 失败**；修复后的代码全部通过。

1. 空文件可以备份并删除。
2. 同一路径连续清理保留不同版本的备份。
3. 会话接口拒绝错误的 ID 类型和非布尔 `dryRun`。
4. 文件删除后会话缓存立即失效。
5. Cursor 回灌保留已有孤儿 KV 正文。
6. 会话头不可读时不把所有 transcript 判成孤儿。
7. 空回灌选择不能变成全部回灌。
8. 未知键族引用的 blob 必须保留。
9. 保留的无主 blob 引用的后代必须保留。

这些对照用例验证行为，不依赖源码字符串匹配。其他新用例通过临时库锁、触发器和 SQL 错误注入验证回滚路径。

## 验证边界

- 未在真实会话数据库上执行清理、回灌或压力测试；未证明所有外部工具版本的私有格式兼容。
- 未模拟断电、真实磁盘耗尽或提交阶段硬件故障。跨独立 SQLite 文件仍不能保证全局原子提交，恢复依赖同一操作的完整备份。
- 文件系统操作不能隔离外部进程的并发修改；单实例互斥不等于多个 Inspector 实例之间的全局文件锁。
- 浏览器移动端检查属于模拟，不等于真机测试；未做独立屏幕阅读器验收。
- 本节为本地验证记录，不替代对应提交的 Linux/macOS 远程 CI 矩阵结果。
